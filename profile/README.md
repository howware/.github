## Howware · From know-how to done

**Your know-how, put to work by AI.** You state the rules in your own words; an AI agent follows them, with a few
exact tools and a memory you own. No app to build, no one to hand it off to, no waiting.

*Hardware runs it. Software executes it. Howware knows how.* — [howware.org](https://howware.org) ·
[en español](https://howware.org/es/)

| Repository | What it is |
|---|---|
| [howware](https://github.com/howware/howware) | The idea: manifesto, whitepaper, specification, the `howware-builder` and `howware-review` skills, and a template |
| [finanzas-personales](https://github.com/howware/finanzas-personales) | The first howware: personal finances without an app — statements, categories that learn, budgets, card payments |
| [mx-bank-statement-reader](https://github.com/howware/mx-bank-statement-reader) | `mxbank`: reads Mexican bank statement PDFs locally and outputs anonymized, reconciled JSON |
| [long-term-memory-for-AI](https://github.com/howware/long-term-memory-for-AI) | A local, append-only memory for AI agents: facts with validity, events, queries without SQL |

Everything is open source — code under Apache 2.0, texts under CC BY 4.0 — and small on purpose, so it can be
reviewed. Found a privacy or security problem? Report it privately from the repository's **Security** tab.
