## Howware · From know-how to done

**Your know-how, put to work by AI.** You state the rules in your own words; an AI agent follows them, with a few
exact tools and a memory you own. No app to build, no one to hand it off to, no waiting.

*Hardware runs it. Software executes it. Howware knows how.* — [howware.org](https://howware.org) ·
[en español](https://howware.org/es/)

| The idea | |
|---|---|
| [howware](https://github.com/howware/howware) | Manifesto, whitepaper, specification, the `howware-builder` and `howware-review` skills, and a template |

| Howwares | The job |
|---|---|
| [finanzas-personales](https://github.com/howware/finanzas-personales) | Personal finances without an app: statements, categories that learn, budgets, card payments |
| [todo](https://github.com/howware/todo) | Getting Things Done without an app: capture, clarify, what to do now, weekly review |
| [facturacion](https://github.com/howware/facturacion) | Invoicing for Mexican freelancers: bank deposits become the invoices to issue, checked against what was stamped |

| Adapters | Shared by howwares; they connect them to documents and data, keeping personal data at the edge |
|---|---|
| [long-term-memory-for-AI](https://github.com/howware/long-term-memory-for-AI) | The memory: local, append-only, facts with validity, events, queries without SQL |
| [mx-bank-statement-reader](https://github.com/howware/mx-bank-statement-reader) | `mxbank`: Mexican bank statement PDFs to anonymized, reconciled JSON |
| [mx-sat-documents](https://github.com/howware/mx-sat-documents) | `mxsat`: SAT invoices (CFDI) and declaration receipts, with personal data kept local |

Everything is open source (code under Apache 2.0, texts under CC BY 4.0) and small on purpose, so it can be
reviewed. Found a privacy or security problem? Report it privately from the repository's **Security** tab.
